# OrderHubProject

Учебный проект на C# для работы с заказами, товарами и складом. Проект демонстрирует применение коллекций .NET, интерфейсов сравнения и сортировки, а также LINQ и итераторов по мере выполнения этапов задания.

## 🛠 Технологии

- **C# / .NET**
- Коллекции `List<T>` и `Dictionary<TKey, TValue>`
- Интерфейсы `IComparable<T>` и `IComparer<T>`
- Сортировка с использованием `Comparison<T>` и лямбда-выражений
- Visual Studio 2022
- Git и GitHub

## 📁 Структура проекта

```text
OrderHubProject/
├── src/
│   └── OrderHub/
│       ├── Domain/       # Модели предметной области
│       ├── Services/     # Логика работы с данными
│       └── Program.cs    # Демонстрация работы приложения
└── docs/
    └── report.md         # Отчёт по выполненным этапам
```

## 📦 Основные возможности

- Работа с заказами и товарами.
- Хранение товаров на складе с использованием `Dictionary`.
- Сортировка каталога по цене и названию.
- Сравнение объектов с помощью `IComparable<T>` и `IComparer<T>`.
- Использование лямбда-выражений для пользовательской сортировки.

## 🚀 Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/LIJTA3U/OrderHubProject.git
   ```

2. Откройте решение в **Visual Studio 2022**.
3. Установите проект `OrderHub` запускаемым, если это необходимо.
4. Запустите приложение с помощью **F5** или **Ctrl + F5**.
